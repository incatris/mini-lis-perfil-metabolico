Registro de paciente, trazabilidad de muestra, alicuotado e ingreso posterior de resultados.

Memoria local: los datos quedan guardados en este navegador/computador. Use “Descargar respaldo” al finalizar cada sesión. Si el archivo se abre en otro computador, use “Importar respaldo”.
Planilla central: activada. Cada muestra, cambio de estado y resultado se envía automáticamente a Google Sheets.
Listo para enviar

1. Registrar paciente

El sistema asigna automáticamente un ID permanente y único, por ejemplo: FP26-K7M2Q8RX. El mismo ID vincula las muestras PRE y POST.

2. Registrar muestra

Pacientes0 Muestras0

Formato de ID de muestra: FP26-K7M2Q8RX-PRE o FP26-K7M2Q8RX-POST. Se permite una muestra PRE y una POST por paciente. Registre la matriz realmente utilizada y la condición de ayuno cuando esté disponible.

3. Trazabilidad

4. Ingreso posterior de resultados

Friedewald: LDL = Colesterol total − HDL − (Triglicéridos/5), en mg/dL.

El estado avanza una etapa a la vez. “Validada” corresponde al ingreso, revisión e informe final de los resultados.

5. Respaldo y sincronización

Los datos se envían automáticamente a la planilla central. El respaldo corresponde solo a sus datos locales y permite recuperarlos si cambia de equipo o navegador.
